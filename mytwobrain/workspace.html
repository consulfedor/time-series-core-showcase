Весь контекст рядом.

Слева — разговор с агентом. Справа — его основания, план и результат. Откройте документ, проверьте расчёт, затем измените факт: будет видно, почему прежней проверки уже недостаточно.

Учебный макет · данные вымышлены · без вызова моделей и внешних операций. Состояние сохраняется при переключениях, но сбрасывается при перезагрузке.
Рабочая сессия

Сверка поставки

Ожидает проверки

Откройте «Explorer» и выберите файл: его содержимое появится справа. «Проверить» сверяет учебные числа и фиксирует версию. «Обновить факт» меняет входные данные и отменяет актуальность проверки. Решение и отправка поставщику остаются за человеком. Все вкладки читают один объект в памяти страницы; серверное API здесь не вызывается.

вокруг задачи.

Обсуждение не отрывается от основания

Человек читает документ рядом с диалогом. Файл, план и история относятся к одной задаче: не нужно заново объяснять контекст при каждом переключении.

У проверки есть версия и границы

Изменился факт — прежний результат больше не актуален. Видны исходные числа, формула и шаг, который требует решения человека.

Макет показывает взаимодействие, а не обещает автономность

В рабочем харнесе за этим интерфейсом стоят инструменты, права доступа, сохранение истории и наблюдение за исполнением. Здесь представлен один локальный сценарий, без настоящих агентов, API и сохранения на сервере.
