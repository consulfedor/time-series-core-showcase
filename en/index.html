Human · AI · Harness

More work completed, with quality and costs under control.

Saved context, repeatable actions and inspectable checks help work continue from what has already been achieved. Verification depth and parallelism are chosen for the task; they also require time and computing resources.

Less repetitive manual work
Recurring collection and validation run on a schedule. The output is a file and report that can be opened.
A result that can be verified
The source, time range, version and checks belong to the same result. A change makes clear what needs to be checked again.
Resources matched to the task
A script handles a repeatable operation; an agent with the appropriate context and model mode handles analysis. Established procedures can be reused.

Six stages: read the explanation
  1. Goal

    The expected result and the conditions for accepting it.

  2. Plan

    Actions, contributors, dependencies and the next step.

  3. Actions

    Work with materials and tools, with progress kept visible.

  4. Checks

    Compare the specific result with the task and its evidence.

  5. Accepted result

    An inspectable result and the person's decision to accept it.

  6. Retained experience

    Decisions and verified experience available for the next task.

Oversight throughout the work

The contributor, next step, deviations and questions needing a human decision remain visible. Checks assess the result; acceptance is a separate decision.

One working object — UI and APIThe person opens the document and its state in the interface. The agent accesses the same material through tools and APIs.

Application / data and research

A day's data without manual assembly

A daily procedure waits for the input to be ready, builds a Parquet file and checks it against the source history. The day's file and validation report are retained.
